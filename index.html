Android 설치 안내

설치 창이 열리지 않으면 Chrome 메뉴(⋮) → 앱 설치(또는 홈 화면에 추가)를 선택하세요. 이미 설치했다면 홈 화면의 MHSE 아이콘을 눌러주세요.

iPhone / iPad 설치 안내

Safari로 열어주세요.
아래 버튼으로 주소를 복사한 뒤 Safari 주소창에 붙여넣으세요.

  1. Safari에서 공유 버튼 (네모 위 화살표)을 누르세요.
  2. 홈 화면에 추가를 선택하세요.
  3. 이름이 MHSE인지 확인하고 추가를 누르세요.
